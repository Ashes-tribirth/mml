# MML Forge

音源をブラウザ内でAI採譜し、マビノギモバイルの楽譜編集へ貼り付けられる3パートMMLを作る試作ツールです。

## 処理の流れ

`音源 → AI採譜（MIDI相当の音符データ）→ メロディ／和音1／和音2 → MML`

- 音源はサーバーへアップロードしません。
- 採譜モデルもこのサイトから配信され、第三者の変換APIは利用しません。
- 各パートは暫定上限の2,400文字で出力を止めます。
- MIDIも保存できるため、あとで専門エディタで調整できます。

## 精度について

自動採譜は耳コピの下書きです。伴奏の少ない短い区間ほど結果がよく、ボーカル・ドラム・複数の楽器が混ざったフル楽曲では誤音が混じります。ゲーム内の試聴で必ず確認してください。
